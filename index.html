Before you go on stage
  • Voice following uses Chrome's speech service, so it needs Wi-Fi or cell signal.
  • The first time you tap Start, Chrome asks for the microphone. Allow it.
  • If it ever loses you, tap the line you're on. It picks up from there.
  • Auto mode scrolls at a fixed pace with no microphone, as a backup.
  • Turn on Do Not Disturb so a notification can't cover the text.
